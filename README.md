# TORATLAS Alpha v0.5

New in this version:
- Interactive 3D sword study models embedded in archive profiles.
- Drag to rotate, scroll to zoom, pan with right-click/two-finger drag.
- Conceptual models for major sword families/types including katana, tachi, wakizashi, tantō, ōdachi, nagamaki, Zulfiqar, shamshir, jian, longsword, zweihänder, yatagan, pata, kaskara, and others.
- Keeps historical profile layout from v0.4.

Files to upload to GitHub:
- index.html
- records.js

Notes:
- The 3D viewer uses Three.js from a CDN, so internet access is required when viewing the site online.
- Models are stylised study aids, not exact scans of museum artifacts.
