# TORATLAS alpha 0.1

A working zero-cost, static, browser-based educational prototype of the Historical Sword Intelligence & Engineering Laboratory.

## Run
Open `index.html` in a modern browser, or deploy it to any static hosting provider (GitHub Pages, Replit static project). No build, login, package install, API key or card needed.

## Working features
- Responsive dark UI and six navigable workspaces.
- Live keyword filtering against four manually curated Metropolitan Museum of Art catalogue records, with direct source links.
- Local photograph upload and preview without sending data to a server.
- Interactive rectangular-cantilever first-yield load model, with input validation and sensitivity plot.
- Reproducible text report export and browser print-to-PDF.

## Not implemented
- AI-based photograph classification (deliberately disabled and labeled).
- Live museum/API queries, user accounts, persistent database, machine-learning dataset/model training.
- Detailed metallurgy, mesh-based FEA or realistic blade behavior.

## Research boundaries
Catalogue entries are evidence about individual objects. Simulator values are hypothetical modern engineering parameters. No historic steel properties are inferred from pictures.
