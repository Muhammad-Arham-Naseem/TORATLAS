TORATLAS Alpha v0.4 — self-contained static website (index.html + records.js). Replaces raw museum object titles with readable historical profiles. Expand each entry to see origin, date, typology, design, evidence, and source details. Historical media leads are labelled provisional; no AI model is connected. Upload index.html and records.js to the root of GitHub repository; README optional. No API keys, payments, or accounts required beyond existing GitHub hosting.
